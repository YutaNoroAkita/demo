Known Bugs
app.js に仕込まれた3つのバグ
1
入力欄がクリアされない
addTask() でタスク追加後、input.value = '' の1行が抜けている
2
完了カウンターが更新されない
toggleComplete() 内で updateStats() の呼び出しが抜けている
3
削除が別のタスクに当たる
deleteTask() 内の findIndex が id + 1 を検索するオフバイワンエラー
Step 1 — Bug Fix
「バグを全部直して」
たった一言の指示で Claude Code が CLAUDE.md を読み、 コードを解析して3件すべてを修正します。
✓
入力欄クリア — input.value = '' を追加
✓
カウンター更新 — updateStats() を追加
✓
削除バグ — id + 1 → id に修正
